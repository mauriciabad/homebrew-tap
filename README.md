# mauriciabad/tap

Homebrew casks by [Maurici Abad](https://github.com/mauriciabad).

## Sukrara

[Sukrara](https://sukrara.mauri.app/) shows live glucose from a Libre 3 wearer in the Mac menu bar.

```sh
brew install --cask mauriciabad/tap/sukrara
```

Sukrara is signed with a Developer ID and notarized by Apple, so it opens like any other app. It needs macOS 15 on
an Apple silicon Mac.

Not a medical device.

The cask is updated automatically when a new
[Sukrara release](https://github.com/mauriciabad/sukrara/releases) is published.
