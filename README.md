# mauriciabad/tap

Homebrew casks by [Maurici Abad](https://github.com/mauriciabad).

## Sukrara

[Sukrara](https://sukrara.mauri.app/) shows the glucose from a Libre sensor in the Mac menu bar.

```sh
brew install --cask mauriciabad/tap/sukrara
```

Sukrara is not notarized by Apple yet. The first time you open it, macOS says *"Apple could not verify “Sukrara” is
free of malware…"*: click **Done**, open **System Settings → Privacy & Security**, click **Open Anyway** next to
*"“Sukrara” was blocked…"* and confirm with your password. Only once
([Apple's guide](https://support.apple.com/guide/mac-help/mh40616/mac)).

Not a medical device.

The cask is updated automatically when a new
[Sukrara release](https://github.com/mauriciabad/cgm-reading-mac-spike/releases) is published.
